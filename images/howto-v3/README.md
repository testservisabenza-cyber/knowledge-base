# Как пользоваться базой — скриншоты

Чистые исходники в `source/` сняты в браузере 6 октября 2026 года:
светлая тема, режим «Без фона», viewport 1920 × 1080.
В первых шагах на фоне открыта инструкция «Добавить компанию».
В чате показан настоящий ответ о сроке окончания лицензии.

`manifest.json` — актуальный источник настроек сборки: состояния, названия целей,
селекторы, измеренные границы и стрелки. Перед новой съёмкой измерения нужно обновить.
`source/targets.json` сохранён как исторический набор измерений; генератор его больше не читает.
Для старых снимков сохранены согласованные отступ внутрь рамки и обрезка 12 пикселей bitmap справа.

Проверка без записи файлов:

```powershell
npm run screenshots:check -- public/images/howto-v3/manifest.json
```

Пересборка: `node scripts/build-howto-shots.mjs` или
`npm run screenshots:build -- public/images/howto-v3/manifest.json`.
Оба пути используют общий стандарт из `scripts/lib/annotated-screenshot.mjs`.
Техническая проверка не заменяет просмотр итоговых SVG и статьи.
