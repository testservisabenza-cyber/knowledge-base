# Общая инструкция записи в контроллер

Снимки сняты 6 октября 2026 года в авторизованном benzamat ПРО, в окне 1920×1080. Тестовый контроллер «Пенза», ID 33481F76 03373931 5235364C.

Автоопрос временно включён для снимка списка, затем сохранён в исходном выключенном состоянии. Выполнена реальная ручная запись пользователей, транспорта, компаний и лимитов. `write-result.jpg` содержит фактическое уведомление «Данные успешно обновлены», полученное после завершения записи, а не после сохранения формы.

`targets.json` содержит измеренные координаты DOM. SVG собираются `node scripts/build-controller-write-shots.mjs`. Обводки единые для всех шагов, правый скроллбар исключён из видимой области SVG. Исходники сохранены без ретуши. В первом шаге только вводный текст, шаги 2–8 содержат полноэкранные фото.
