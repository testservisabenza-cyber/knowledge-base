# Изменение лимита пользователя

Исходники сняты 6 октября 2026 года в benzamat ПРО через браузер, окно 1920 × 1080. Демонстрационный пользователь: «тест тест». Форма заполнена для иллюстрации и закрыта без сохранения. Последний кадр показывает место проверки значений, а не результат выполненной нами операции.

JPEG — чистые исходники; `targets.json` — измеренные границы элементов DOM; SVG — полный кадр с отдельным векторным слоем выделений. В первых трёх шагах используется `list-unfiltered.jpg`: фильтры пустые, показана вся строка «тест тест». Правая полоса прокрутки обрезается при сборке SVG. Курсор отсутствует. Цвета приложения сохранены; тема базы знаний оформляет окружающую страницу.

Пересборка из корня проекта: `node scripts/build-user-limit-edit-shots.mjs`.

При пересъёмке обновите JPEG и измерения. Если присутствует правая полоса прокрутки, укажите её фактическую ширину в `rightScrollbarWidth` соответствующего кадра в скрипте: SVG обрежет только эту крайнюю полосу, не смещая выделения.
