# Считыватель карт: исходники пользователя

Получены от пользователя 15 октября 2026 года. Все шесть PNG скопированы из вложений
без изменения байтов, размеров и содержимого. Это реальные окна программы
«benzamat ПРО. Считыватель карт» и её уведомления Windows.

| Файл в `source/` | Состояние | Применение в инструкциях |
| --- | --- | --- |
| `01-first-launch.png` | Первый запуск после установки. Адрес сервера указан, ID пустой, считыватель не найден | Первое окно программы и поле адреса сервера |
| `02-user-id-entered.png` | ID пользователя введён, считыватель ещё не подключён | Поле ID пользователя и кнопка «Сохранить» |
| `03-reader-connected.png` | USB-считыватель распознан, карта ещё не считана | Строка «Считыватель, версия ПО» |
| `04-card-read.png` | В окне видны номер карты `76 24 C9 69` и тип `MIFARE 1KB` | Результат чтения, строка «Номер карты», кнопка «Копирование» |
| `05-card-read-and-sent-notifications.png` | Два уведомления: чтение номера карты и успешная отправка номера в benzamat ПРО | Подтверждение чтения и передачи номера в сервис |
| `06-settings-saved-notification.png` | Уведомление «Сохранение данных авторизации»: сохранены адрес сервера и ID пользователя | Подтверждение сохранения настроек программы |

Номер файла соответствует порядку вложений. В инструкции уведомление `06` относится
к сохранению настроек после ввода ID, а уведомления `05` к чтению и отправке карты.
Это разные результаты, их нельзя подменять друг другом.

## Дальнейшая разметка

Исходники сохранять неизменными. Рамки и стрелки добавлять отдельным слоем к копиям
для конкретных шагов. Не использовать старый `pro-reader-usb.png` как чистый исходник:
на нём уже есть разметка. Не восстанавливать скрытые части текста в полях и не
дорисовывать уведомления. Эти кадры предоставлены в размере окон и уведомлений;
не выдавать их за новые полноэкранные снимки 1920 × 1080.

Все шесть исходников использованы в статье `pro-card-reader-setup`.
Разметка описана в `manifest.json`, проверка всех 19 кадров статьи записана в
`visual-review-pro-card-reader-setup.json`. Сводка замены находится в
`docs/reader-screenshots-to-replace.md`.
